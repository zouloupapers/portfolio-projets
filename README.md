# Portfolio — projets web et mobiles

> **EN** — Case studies of the web and mobile products I design and build for French-speaking Africa, mainly Congo-Brazzaville: an e-commerce web agency and three Flutter apps (marketplace, faith content platform, investment demo). Source code is private; this page describes each product, its stack and its status.

## Kitoko Web

**Agence de création de boutiques en ligne pour les commerçants du Congo-Brazzaville** (anciennement Nexoradev).

- Offre centrée sur les **boutiques en ligne** pour les e-commerçants
- Deux formules au choix du client : **paiement unique** ou **abonnement mensuel**
- Présence sur TikTok, Instagram et Facebook

## BigDeal

**Marketplace d'annonces mobile par abonnement** pour Brazzaville, Pointe-Noire et Dolisie.

- Modèle : les **vendeurs** paient un abonnement mensuel, les **acheteurs** utilisent l'app gratuitement, **aucune commission** sur les transactions
- **Flutter** pour l'app, **Supabase** pour la base de données, l'authentification et le stockage
- Paiement **Mobile Money (MTN MoMo et Airtel Money)** intégré et fonctionnel en environnement de test (sandbox)
- Plus de 20 écrans, design system dédié (palette, typographies, composants)
- Lancement prévu d'abord sur **Google Play**

## ChurchStream

**Plateforme de prédications et de livres chrétiens** pour toute la francophonie.

- Deux types de comptes, **fidèle** et **pasteur / église**, qui partagent les mêmes écrans (seul le profil diffère)
- Les pasteurs peuvent **vendre leurs livres** sur la plateforme
- **App Flutter** + **site web de paiement** hébergé sur **Firebase** : [churchstream-15724.web.app](https://churchstream-15724.web.app/)
- Identité visuelle propre (noir et or)

## Biso Invest

**Application de démonstration pour découvrir l'investissement dans des entreprises du Congo-Brazzaville.**

- Mode **démo, sans argent réel** : graphiques de tendance des entreprises, portefeuille, journal des revenus
- Objectif à terme : un partenariat avec un acteur agréé pour relier de vrais paiements **MTN Money / Airtel Money**
- **Flutter**
